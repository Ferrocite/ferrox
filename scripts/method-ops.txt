# Per-method retired-instruction counts, for ops.yml to report.
#
# `scripts/count-ops.sh check` gates the one blessed row in
# `scripts/expected-ops.txt`. This file is the open list: ops.yml measures every
# row here on every run and publishes the numbers, which is what turns a row in
# `scripts/method-counts.txt` from UNBLESSED into a number somebody can read and
# decide to bless. A symbol that inlined into its caller under release will not
# appear in a callgrind profile; that row is reported as not found and the next
# name up is the one to try.
#
# A symbol reported as `not found` inlined into its caller under release: the
# row is then noise, and the name up is the one to try. `ferrox_app::foxy::read_frame`
# and `masque::datagram_encode` are the two that survive for this method.
#

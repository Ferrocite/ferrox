# passes (currently quic::tests::pem_wraps_at_sixty_four_columns). `ir` is
# retired instructions under callgrind, exact across machines. A row whose
# value is UNBLESSED fails the check while printing the measured count: copy
# that number here only after reading the diff it came from and deciding the
# added or removed instructions are the change intended — never to silence
# the gate. Nearby code growth can shift a row by a few instructions under
# thin-LTO without touching the function; that re-bless names the nearby
# diff as its cause, same as any other. Symbols must be unique substrings
# (see count-ops.sh); tiny helpers vanish into their callers under release
# inlining even with line tables, so gate the caller that survives, not the
# leaf that does not. The syscall table the script prints alongside is
# information, not a gate.
